1. Inférence : le modèle XGBoost prédit un score par ETF par jour (prédiction de ret_10d_fwd z-scoré)
2. Z-score cross-sectionnel (ligne ~998) : les scores bruts sont re-normalisés par jour : score_z = (score - mean_etfs) / std_etfs
2. Chaque jour, les scores sont centrés/réduits → comparables entre ETFs
3. TOP_N filter (ligne ~1004) : on garde seulement les N meilleurs scores positifs par jour, au plus 1 ETF par bloccorrélé (IVV/SUSA/ACWI = même bloc). Les autres sont mis à NaN.
4. Softmax (dans _alloc, ligne ~151) : parmi les ETFs score > 0 restants :
w = softmax(score / temperature = 1 )
4. Convertit les scores en poids (0→1, somme = 1)
5. Pondération Sharpe (ligne ~166) : combined = w_softmax × sharpe_expanding^power puis renormalisé. Avec SHARPE_POWER=0, ce facteur = 1 → les poids softmax passent directement.
6. Allocation : les poids finaux déterminent la répartition du capital entre les ETFs sélectionnés. Le reste va en cash.
