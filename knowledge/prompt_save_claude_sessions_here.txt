Set up automatic syncing of Claude Code conversations into this git repository.

## How it works

- A single generic script at `~/scripts/sync-claude-convs.sh` handles all projects
- It auto-detects the current git repo via `git rev-parse --show-toplevel`
- Conversations are committed to a dedicated daily branch `claude_session_DDMMYYYY` using `git worktree` — the current working branch is never touched
- A lockfile serializes concurrent Stop hooks (multiple parallel sessions in the same project)
- Each project gets its own `.claude/settings.json` with a `Stop` hook calling that script


## Step 2 — Create the generic sync script

Create `$HOME/scripts/sync-claude-convs.sh` (create `~/scripts/` if needed).  
**If the file already exists, show me its current content and skip creation.**

```bash
#!/bin/bash
# sync-claude-convs.sh — generic multi-project Claude conversation sync
# - Commits to a dedicated daily branch: claude_session_DDMMYYYY
# - Uses git worktree to avoid disturbing the current working branch
# - Lockfile prevents race conditions with parallel Claude sessions

set -euo pipefail

CLAUDE_PROJECTS_DIR="$HOME/.claude/projects"
CONV_SUBDIR="knowledge/claude-conversations"

# --- Detect current repo ---
REPO=$(git -C "$PWD" rev-parse --show-toplevel 2>/dev/null || true)
if [ -z "$REPO" ]; then
  echo "[sync-claude] WARN: no git repo found in $PWD, aborting." >&2
  exit 0
fi

# --- Lockfile: serialize concurrent Stop hooks ---
LOCKFILE="/tmp/claude-sync-$(basename "$REPO").lock"
exec 9>"$LOCKFILE"
if ! flock -w 10 9; then
  echo "[sync-claude] WARN: could not acquire lock after 10s, aborting." >&2
  exit 0
fi

BRANCH="claude_session_$(date '+%d%m%Y')"
WORKTREE="/tmp/claude-sync-$(basename "$REPO")-$$"
DEST_TMP=$(mktemp -d)

cleanup() {
  rm -rf "$DEST_TMP"
  git -C "$REPO" worktree remove "$WORKTREE" 2>/dev/null || true
}
trap cleanup EXIT

# --- Find ALL conversations for this project ---
PROJECT_DIR=""
for d in "$CLAUDE_PROJECTS_DIR"/*/; do
  if [ -f "$d/metadata.json" ] && grep -q "$REPO" "$d/metadata.json" 2>/dev/null; then
    PROJECT_DIR="$d"
    break
  fi
done

if [ -z "$PROJECT_DIR" ]; then
  echo "[sync-claude] INFO: no metadata match, falling back to recent files (24h)." >&2
  find "$CLAUDE_PROJECTS_DIR" -name "*.jsonl" -mmin -1440 -exec cp -u {} "$DEST_TMP/" \;
else
  echo "[sync-claude] INFO: matched Claude project: $PROJECT_DIR" >&2
  find "$PROJECT_DIR" -name "*.jsonl" -exec cp -u {} "$DEST_TMP/" \;
fi

# --- Setup worktree on the claude branch ---
cd "$REPO"

if ! git rev-parse --verify "$BRANCH" >/dev/null 2>&1; then
  git branch "$BRANCH"
  echo "[sync-claude] INFO: created branch $BRANCH" >&2
fi

git worktree add "$WORKTREE" "$BRANCH"
mkdir -p "$WORKTREE/$CONV_SUBDIR"
cp -u "$DEST_TMP/"*.jsonl "$WORKTREE/$CONV_SUBDIR/" 2>/dev/null || true

# --- Commit inside the worktree ---
cd "$WORKTREE"
git add "$CONV_SUBDIR/"

if ! git diff --cached --quiet; then
  COUNT=$(git diff --cached --name-only | wc -l)
  git commit -m "claude: sync $(date '+%Y-%m-%d %H:%M') — ${COUNT} file(s) [$(basename "$REPO")]"
  echo "[sync-claude] OK: committed to $BRANCH (${COUNT} file(s))" >&2
else
  echo "[sync-claude] OK: nothing to commit." >&2
fi
```

Then: `chmod +x $HOME/scripts/sync-claude-convs.sh`

## Step 3 — Configure the project-level Claude hook

Create or edit `$REPO/.claude/settings.json`.  
**If the file already exists, merge carefully — do not overwrite existing keys.**

```json
{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "/home/<USER>/scripts/sync-claude-convs.sh"
          }
        ]
      }
    ]
  }
}
```

Replace `<USER>` with the actual username from Step 1. Use the full absolute path — no `~`.
